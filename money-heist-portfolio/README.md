# Anees Ahmed — Money Heist Portfolio

Personal portfolio of **Anees Ahmed**, an Agentic AI student at Saylani Mass IT Training (SMIT), aspiring web developer, and former Pizza Max Training Manager.

## Website

Open **index.html** in a modern browser or run `python -m http.server 8000` from this folder.

## Structure

- `index.html` — semantic single-page website; red-suit hero and blue-light About photos
- `style.css` — responsive design, red #E50914, matte black #141414, gold accent
- `script.js` — interactive menu, theme/audio controls and email-based contact form
- `assets/anees-red-suit.jpg` — original supplied hero photo
- `assets/anees-blue-portrait.jpg` — original supplied secondary photo (JPEG-encoded original)
- `resume/Anees_Ahmed_Public_Resume.pdf` — public-safe resume (no CNIC, DOB or home address)

## Edit your details

Edit `index.html` for biography, skills, dates, contact and the six icon-only social links. Update theme colors in `style.css`. Keep names/paths when replacing assets. The contact form uses `mailto:` and requires the visitor's email app; no server-side collection.

## Publication

This project is located at `money-heist-portfolio/` inside the existing `AneesQurashi/Anees-Portfolio` repository, **preserving the repository's original Neon Glass portfolio**. GitHub Pages deployment is separate and depends on the repository Pages settings. To host only this folder, use a Pages deployment workflow or move/copy it into a dedicated Pages repository.
