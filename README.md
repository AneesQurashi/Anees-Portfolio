## ✨ Key Features

* **🎨 Dynamic Neon Aura Particle Engine:** A custom-built HTML5 canvas background featuring mouse interaction modes (**Attract, Repel, Vortex**), adjustable particle density, speed velocity, and link radius.
* **🎛️ Particle Aura Studio Control Panel:** A floating glassmorphism widget allowing real-time switching between 4 neon color palettes (**Cyber Neon, Emerald Aurora, Golden Amber, Electric Violet**).
* **🔊 Web Audio API Synthesizer:** Built-in zero-dependency sound feedback for user clicks and theme toggles.
* **⚡ Interactive Beach Equestrian Artwork:** Custom vector illustration honoring the Seaview Karachi horse-riding background, representing balance and leadership under high-volume pressure.
* **📄 Integrated Resume & Modal Viewer:** Fully formatted CV popup with print functionality and direct WhatsApp/Email inquiry triggers.
* **📱 Fully Responsive Layout:** Crafted with modern Tailwind CSS utilities and glassmorphism styling for seamless viewing across mobile, tablet, and desktop screens.

## 🛠️ Built With

* **HTML5 / CSS3:** Semantic structure and custom glassmorphism variables.
* **Tailwind CSS (CDN):** Modern utility-first styling and responsive breakpoints.
* **FontAwesome 6.5.1:** Crisp hospitality, UI, and brand icons.
* **Google Fonts:** *Outfit* and *Space Grotesk* typography.
* **Vanilla JavaScript (ES6+):** Object-oriented particle physics engine and UI state controllers.
